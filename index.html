01 / 访问链接

https://lingguixi1469.pages.dev/AI主数据智能治理平台_企业演示版.html

02 / 项目背景

基于制造业备品备件主数据治理（MDM）真实业务需求，采用 Vibe Coding 模式，借助 Kimi-K3 全栈独立开发单文件离线演示平台。本人负责架构设计与意图把控，Kimi-K3 负责代码生成与实现细节，实现从 CSV 脏数据接入到跨系统分发的完整闭环。无需服务器部署，数据存储于浏览器本地 IndexedDB，适合企业内网安全环境。

03 / Vibe Coding 迭代流程

需求拆解 → 建立全局宪法（同义词字典 / 编码前缀 / 相似度阈值）→ 结构化提示工程 → Kimi-K3 生成核心代码 → 人工审查关键逻辑与边界条件 → 多轮迭代调优 → 质量验收。

04 / 核心功能
  1. CSV 脏数据接入：支持拖拽上传，自动识别 UTF-8 BOM / UTF-8 / GBK 编码，完成缺失值填充、格式标准化、描述文本预提取。
  2. 智能字段映射：自动识别 7 个标准字段，支持手动调整映射关系。
  3. AI 语义聚类合并：基于同义词字典归一 + n-gram（2-3 字符）+ TF-IDF + 余弦相似度算法，自动识别相似数据并聚类合并，数据压缩率 ≥60%，自动合并率 ≥50%，准确率 ≥90%。
  4. 冲突审核：支持 AUTO_MERGE（相似度 >0.85 自动合并）、REVIEW（中置信度人工审核）、NEW（建议新建）三种决策模式。
  5. 数据质量评估：五维评分报告（完整性、准确性、一致性等），引入 Isolation Forest 异常检测，字段完整率 ≥85%。
  6. 自然语言搜索：支持“SKF 品牌 DN200 的机械密封”等语义查询，召回率 ≥85%，响应时间 ≤500ms。
05 / 技术栈 & 亮点

Python Flask + scikit-learn + SQLite（后端），HTML5 / CSS3 / JS + IndexedDB（前端），借助 Kimi-K3 辅助代码生成、算法设计与工程优化。前后端分离架构，后端 RESTful API + 前端单 HTML 零依赖；同义词扩展、正则实体抽取（品牌 / 型号 / DN / 压力 / 材质）；按品类自动分配 MDM 编码前缀（MDM-S 机械密封、MDM-B 轴承等）。
